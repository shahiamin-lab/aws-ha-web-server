# Web Application Source

The web page is generated by the EC2 launch template UserData script in
`infrastructure/ha-web-server.yaml`.

At instance startup, the script retrieves the instance ID and Availability
Zone using IMDSv2, then writes the HTML page served by Apache. This keeps
the displayed instance details specific to the EC2 instance serving the
request.

The page includes:
- AWS Cloud Architecture Capstone project title
- Author name
- EC2 instance ID
- Availability Zone
- Load balancing and health-check status

See the `UserData` section of the CloudFormation template for the actual
HTML and startup implementation.
